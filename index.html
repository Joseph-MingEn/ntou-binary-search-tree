    03 / PRINCIPLES & REFLECTION

    從比較到走訪：二元搜尋樹的原理

    先用範例建立樹，再切換走訪方式，對照輸出與節點編號。

    01

    BST 的大小規則

    對每個節點都成立：左子樹中的值全部小於節點，右子樹中的值全部大於節點。本頁不收重複值。插入時從根節點比較，走到空位才建立新節點，因此數字的位置由比較路徑唯一決定。

    02

    搜尋與刪除

    搜尋沿著和插入相同的路徑前進；相等就是找到，走到空位就是不存在。刪除分三種：葉節點直接移除、單一子節點由孩子接替、兩個子節點以右子樹最小值（中序後繼）接替，再移除後繼原位置。

    03

    四種走訪口訣

    • 前序：根 → 左 → 右（根先輸出）
    • 中序：左 → 根 → 右（BST 會由小到大）
    • 後序：左 → 右 → 根（根最後輸出）
    • 層序：由上往下、每層由左到右
    04

    效率取決於樹高

    插入、搜尋、刪除都沿著一條根到節點的路徑，時間為 O(h)，其中 h 是樹高。樹形均衡時約為 O(log n)；若依序插入已排序數列，樹可能歪成長鏈，最壞會到 O(n)。

    WORKED EXAMPLE

    範例數列的四種輸出

    插入 48, 25, 72, 12, 36, 60, 90, 30, 42 後，四種走法會產生不同順序。

    前序
    48, 25, 12, 36, 30, 42, 72, 60, 90
    中序
    12, 25, 30, 36, 42, 48, 60, 72, 90
    後序
    12, 30, 42, 36, 25, 60, 90, 72, 48
    層序
    48, 25, 72, 12, 36, 60, 90, 30, 42
    核心 C++ 程式：插入、搜尋、刪除與四種走訪
    #include <iostream>
#include <queue>
using namespace std;

struct Node { int value; Node *left, *right; };
void visit(Node* t) { cout << t->value << ' '; }

Node* insert(Node* root, int x) {
    if (!root) return new Node{x, nullptr, nullptr};
    if (x < root->value) root->left = insert(root->left, x);
    else if (x > root->value) root->right = insert(root->right, x);
    return root; // 相等時不重複插入
}

bool search(Node* t, int x) {
    if (!t) return false;
    if (x == t->value) return true;
    return x < t->value ? search(t->left, x) : search(t->right, x);
}

Node* removeNode(Node* t, int x) {
    if (!t) return nullptr;
    if (x < t->value) t->left = removeNode(t->left, x);
    else if (x > t->value) t->right = removeNode(t->right, x);
    else {
        if (!t->left) { Node* r = t->right; delete t; return r; }
        if (!t->right) { Node* l = t->left; delete t; return l; }
        Node* s = t->right;
        while (s->left) s = s->left; // 右子樹最小值：中序後繼
        t->value = s->value;
        t->right = removeNode(t->right, s->value);
    }
    return t;
}

void preorder(Node* t)  { if (!t) return; visit(t); preorder(t->left); preorder(t->right); }
void inorder(Node* t)   { if (!t) return; inorder(t->left); visit(t); inorder(t->right); }
void postorder(Node* t) { if (!t) return; postorder(t->left); postorder(t->right); visit(t); }

void levelOrder(Node* root) {
    queue<Node*> q; if (root) q.push(root);
    while (!q.empty()) {
        Node* t = q.front(); q.pop(); visit(t);
        if (t->left) q.push(t->left);
        if (t->right) q.push(t->right);
    }
}

    前三種走訪的程式只有 visit 位置不同，遞迴堆疊會記住尚未完成的節點；層序改用先進先出的佇列，確保同一層先走完。

    實作心得

    操作後我發現，二元搜尋樹的形狀不只看有哪些數字，也受插入順序影響。中序走訪能把 BST 輸出成排序結果；但普通 BST 不會自動平衡，遇到有序輸入時可能退化成長鏈。透過搜尋路徑、刪除情況和四種走訪的對照，我更能看出每一步是在維持哪個規則，而不只是背樹的圖形。
